# Стартовий проєкт

1. Відкрийте проєкт у GitHub Codespaces (Code → Codespaces → Create codespace) або локально: `python -m venv .venv`, активація, `pip install -r requirements.txt`.
2. Знайдіть свій файл у папці `tasks/` і реалізуйте його за карткою.
3. Запускайте відкриті тести: `pytest`.
4. Змінюйте лише свій файл у `tasks/` (і за бажанням `tests/test_my.py`).
5. Теоретичні завдання 11-15 не мають тестів: напишіть відповідь у `answers/task_NN.md` під рядком «Відповідь:».
