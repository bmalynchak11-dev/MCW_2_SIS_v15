# Завдання 12. Одне слово, два значення (легке)

У застосунку доставки їжі слово «адреса» вживають у двох частинах системи. Для кур'єрів це місце доставки з під'їздом, поверхом і кодом домофона. Для бухгалтерії це юридична адреса клієнта для рахунку. Розробник пропонує одну спільну модель `Address` з усіма полями для всіх частин.

**Що потрібно зробити.** Поясніть, що таке обмежений контекст, чому спільна модель шкодить обом командам і як діяти натомість. Наведіть, як зв'язати дві моделі однієї реальної сутності.

**Обсяг:** 5-8 речень. Матеріал: лекція 6.
